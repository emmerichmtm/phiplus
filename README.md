# phiplus

Implementation of the phiplus indicator for multi-objective optimization proposed in:

MaoMao Liang, Babooshka Shavazipour, Bhupinder Saini, Michael Emmerich, and Kaisa Miettinen. 2024. A Modified
Preference-Based Hypervolume Indicator for Interactive Evolutionary Multiobjective Optimization Methods. In Interna-
tional Joint Conference on Computational Intelligence. SCITEPRESS, 214–221.
(https://www.scitepress.org/Papers/2024/129346/129346.pdf)
